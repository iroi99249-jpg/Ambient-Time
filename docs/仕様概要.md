# Ambient Time 仕様概要

## 目的
Windowsを一定時間操作しなかったとき、自動的に全画面のアンビエント表示を起動する。

## 確定仕様
- ElectronでWindowsアプリ化
- 起動方式は全画面
- 背景は動的シーン
- 無操作時間はユーザーが自由設定
- 日本語を標準言語とする
- Dark Glass、シーン連動アクセントカラー、左サイドバー、滑らかなアニメーション
- 更新履歴とバージョン表示を搭載
- GitHub Releasesによる配信を将来の更新方式とする

## 初期シーン
- Rainy Night（雨の夜）
- Summer Sky（夏空）
- Snowfall（雪景色）
- Deep Space（深宇宙）

## 主要ページ
ホーム、外観、シーン、ウィジェット、自動起動、パフォーマンス、設定、更新履歴、アプリについて。

## 非機能要件
- UIと無操作監視を分離する
- contextIsolationを有効化しnodeIntegrationを無効化
- 低負荷描画、FPS制限、省電力設定を用意する
- ローカライズ文字列を画面のコードに直書きしない
- 自動起動処理はゲーム・ロック・スリープ状態との競合を避ける

## 現在の制限
現行のmain.jsは基盤確認用の暫定実装。操作を検知して表示を閉じる処理、設定値のIPC連携、スリープやロックの考慮、画面ごとのウィンドウ管理は未実装。
